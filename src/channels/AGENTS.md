# AGENTS · src/channels

## 范围
- 适用：`src/channels/**`
- 继承：根级 `AGENTS.md`
- 冲突处理：本文件优先（仅限 `src/channels/**`）

## 局部规则（差异项）
- 目标：保持各渠道接入一致性，避免供应商特化逻辑外溢到公共层。
- 分层边界：`shared/` 只放跨渠道稳定能力；供应商差异仅放在 `telegram/`、`feishu/`。
- 配置边界：渠道开关/凭据校验集中在各自 `config.ts` 与 schema，禁止分散读取环境变量。
- 协议边界：入站标准化后再进入编排层，避免将厂商字段透传到核心模型。
- 回写边界：被动回复链路统一走 channel client，禁止在上层拼接厂商请求。
- 错误处理：渠道故障应显式暴露并可观测，禁止静默降级吞错。

## 变更前检查
- 明确本次改动属于 `shared` 还是供应商目录；不确定时先落供应商目录。
- 检查是否破坏 WebUI 与 bot channel 可并行运行的前提。

## 变更后检查
- 验证入站→标准化→编排→被动回复链路闭环。
- 验证配置缺失/无效时的失败行为可预期且可定位。
