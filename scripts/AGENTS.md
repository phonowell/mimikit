# AGENTS · scripts

## 范围
- 适用：`scripts/**`
- 继承：根级 `AGENTS.md`
- 冲突处理：本文件优先（仅限 `scripts/**`）

## 局部规则（差异项）
- 目标：脚本应可直接执行、可复现、易审查，不引入隐藏副作用。
- 执行入口：脚本保持单一职责；参数解析与核心逻辑分离。
- 输出约束：命令行输出优先结构化与稳定格式，便于 CI/自动化消费。
- 依赖约束：优先复用 `scripts/shared/**`；新增依赖需有明确收益。
- 失败策略：参数/环境不满足时快速失败并给出可执行修复提示。

## 变更前检查
- 明确脚本运行上下文（主仓库/工作树/CI）与输入来源。
- 识别是否已有等价脚本可复用，避免命令能力重复。

## 变更后检查
- 至少验证一次真实命令路径（最小参数集）。
- 确认失败分支输出清晰，返回码符合预期。
