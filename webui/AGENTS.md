# AGENTS · webui

## 范围
- 适用：`webui/**`
- 继承：根级 `AGENTS.md`
- 冲突处理：本文件优先（仅限 `webui/**`）

## 局部规则（差异项）
- 目标：保持 WebUI 交互可读、可维护，不引入框架级复杂度。
- 技术边界：维持当前原生 `html/css/js` 结构，不新增前端框架与构建链。
- 改动粒度：优先按功能拆分小模块，避免继续增大单文件复杂度。
- 样式约束：优先复用已有 class/变量与样式分层（`base/layout/components`），避免平行体系。
- 交互约束：改动事件流时同步检查 `messages/*` 控制器链路，避免 UI 状态与数据状态脱节。
- 测试策略：仅补充覆盖真实交互回归风险的最小必要测试；不新增文案耦合测试。
- 浏览器约束：禁止使用真实浏览器测试 `webui`（含人工打开页面、Playwright、CDP 类浏览器自动化）；改用代码阅读、静态检查与最小必要的非浏览器验证。

## 变更前检查
- 明确变更是否影响 `index.html` 结构或 `messages/*` 渲染链。
- 识别可复用的现有样式与模块，避免重复实现。

## 变更后检查
- 以代码路径审查、静态检查或最小必要测试验证关键路径：消息渲染、发送/删除、面板切换（任务/计划/聚焦）。
- 以结构与样式规则检查确认移动端和桌面端布局逻辑可用；不使用真实浏览器验收。
